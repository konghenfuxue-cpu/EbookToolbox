# Windows 第一次下载与使用

核对日期：2026-10-19。先用自己写的两个 TXT 完成一次练习，再处理电子书副本。

## 选哪个文件

| 下载项 | 给谁用 | 如何启动 |
| --- | --- | --- |
| Release 的 `EbookToolbox-portable.zip` | 普通 Windows 用户 | 全部解压后双击内部 EXE |
| `EbookToolbox-portable.zip.sha256` | 校验上面 ZIP 是否完整 | 文本校验值，不是软件 |
| `Source code (zip)`、Code → Download ZIP | 要运行源码或参与开发的人 | 需要 Python 与依赖；其中没有现成 EXE |

本项目没有 Setup.exe 安装器。便携 ZIP 中的 EXE 已包含 Python/Qt 所需资源；不需要另外安装 Python、uv、Git 或 Calibre 才能使用基本工具。

**版本提醒：**核对时最新正式下载仍为 [v0.1.0（2026-10-03 北京时间发布）](https://github.com/konghenfuxue-cpu/EbookToolbox/releases/tag/v0.1.0)，附件约 60.4 MiB。`main` 后续合并了 TXT 写入保护、首页及设置改进，但版本号也仍为 0.1.0。单看“0.1.0”无法区分构建；README 当前截图来自新版源码，旧 Release 的页面可能不同。要使用这些后续修复，请按下文源码路线；本教程不发布新二进制，也不把旧包说成包含新版修复。

## 下载、解压和第一次启动

1. 打开上面的 Release 页面，展开 **Assets**，点击 `EbookToolbox-portable.zip`。如果只看到 Source code，先确认展开了完整 Assets 区域。
2. 等待浏览器显示下载完成；不要打开 `.crdownload` 或不完整 ZIP。
3. 右键 ZIP → **全部解压缩**。例如选择 `C:\Tools\EbookToolbox-v0.1.0`，不要解压覆盖旧版。
4. 打开解压目录，向内找到 **`EbookToolbox.exe` 与 `_internal` 在同一层**的文件夹。保持该层所有文件完整，不能只把 EXE 拖到桌面。需要桌面入口时创建快捷方式。
5. 双击 `EbookToolbox.exe`。预期出现左侧工具导航和右侧功能区；无需登录、激活或管理员权限。第一次可能比后续启动慢。

建议 Windows 11 x64；本轮验证环境为 Windows 11，Windows 10 x64、ARM 与其他系统未验收，不提供 macOS/Linux 成品包。可选的 Calibre 元数据读取要求另装 Calibre；它不是基本修复功能的前提。

若出现 Windows 安全提示，先核对下载来源和校验值。确认可信后再决定是否使用系统提供的继续入口；若显示明确威胁或校验不同，停止运行并重新下载，不要关闭安全软件或从其他站点补 DLL。

可选完整性核对：在 ZIP 所在文件夹地址栏输入 `powershell` 回车，运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\EbookToolbox-portable.zip'
```

用记事本打开同 Release 的 `.sha256` 文件逐字核对。本次 GitHub 公布的 v0.1.0 ZIP 值是 `56ccc06ccf5285b1585895090caab0dcc5a6afab28b99b0bd144eabad2f400ab`；后续新版要使用其自身校验值。

## 最小练习：合并两个 TXT

1. 在“文档”中新建 `EbookToolbox练习` 文件夹。打开记事本，输入 `第一章 初次见面` 和下一行 `这是我写的第一段示例。`，另存为 UTF-8 的 **`[示例作者]教程01.txt`**。
2. 再新建一个记事本文件，输入 `第二章 再次出发` 和下一行 `这是我写的第二段示例。`，同样保存为 **`[示例作者]教程02.txt`**，放进同一文件夹。不要把输出文件也放成输入 TXT。
3. 在程序左侧选择 **TXT 工具**，找到“排版并按作者合并”区域。点“输入文件夹”旁的“浏览…”，选择上面的练习文件夹。
4. “输出文件夹”先留空；不要勾选允许覆盖选项。点 **开始排版并合并**，等待结果区域显示完成与输出位置。
5. 到练习文件夹中打开新生成的 **`EbookToolbox-合集`**。应有一份示例作者合集 TXT，包含两段正文；两个原始 TXT 仍保留。
6. 用记事本打开输出，搜索“第一章”和“第二章”，核对两段都存在、先后顺序符合预期。成功计数对应作者合集，不一定等于输入文件数。

名字前面的半角 `[示例作者]` 用于分组；缺少作者前缀的文件可能被跳过。同作者的文件才进入同一合集。此练习仅用于观察输出；旧 v0.1.0 不包含后续完整写入保护，真实批量任务推荐先使用含修复的源码版，并始终保留原稿副本。

## 使用 EPUB 目录修复

先把有权使用的 EPUB 复制到练习文件夹，保留原件。在左侧选 **EPUB 目录修复**，“EPUB 文件”选这个副本，“输出文件”保持新文件名（默认同目录 `原名_toc_fixed.epub`），首次保持默认“重建已有目录”，点击 **开始修复**。

成功后核对页面显示的输出位置与警告，在自己的 EPUB 阅读器中打开新文件，点目录的第一章、最后一章。无法识别章节或缺失文件时保留错误和原件，不要不断重复修复。图片压缩、综合修复是独立操作，不会因为做目录修复而自动执行。图片压缩改变画质，首次单独对一本副本试用。

内部结构检查、Calibre 元数据读取、EPUBCheck 是不同能力；当前没有集成 EPUBCheck。显示任务成功不能替代目标阅读器检查或完整标准校验。

## 新版源码路线（可选）

需要新版修复但暂时没有新 Release 时使用此路线。先在 [uv 官方安装说明](https://docs.astral.sh/uv/getting-started/installation/)核对安装方式。在普通 PowerShell 中运行官方 WinGet 入口：

```powershell
winget install --id=astral-sh.uv -e
```

按提示确认来源与许可，完成后重新打开 PowerShell，运行 `uv --version` 应显示版本号。没有 WinGet 时使用同页提供的官方安装器；不要从第三方下载站取工具。

从仓库 **Code → Download ZIP** 下载 `EbookToolbox-main.zip`，全部解压到新目录。进入包含 `main.py`、`pyproject.toml`、`uv.lock` 的那层，在地址栏输入 `powershell` 后逐行运行：

```powershell
uv sync --locked --no-dev --python 3.11
uv run --no-sync python main.py
```

uv 会准备 Python 3.11（本机没有可用解释器时需要下载）、创建 `.venv`，并按锁文件安装 PySide6、Pillow、qt-material 等应用依赖；首次需要网络和足够磁盘空间。`--no-dev` 不安装构建与测试工具。出现依赖失败就停在这一步，保留完整错误，不要把已出现 `.venv` 当安装成功。关闭程序后再次启动仍运行第二行。

源码版首页列出可用功能；设置页可以查看构建身份、修改主题与保存窗口大小。源码运行未必有构建日期，显示“未知”是正常结果。可选构建和开发检查见 [README](../README.md#开发环境运行)，普通使用不需要自己打包 EXE。

## 文件保存、更新与恢复

| 内容 | 保存位置 |
| --- | --- |
| 输入 EPUB/TXT | 你选定的原位置，首次请用副本 |
| TXT 合集 | 默认在输入目录的 `EbookToolbox-合集`，以界面实际结果为准 |
| EPUB 修复结果 | 默认在输入文件旁的新文件，或你指定的位置 |
| 检测报告 | 本次会话内；手动导出后在你选的 JSON 文件中 |
| 新版主题/窗口设置 | 设置页显示的当前用户 `settings.json` 路径，不在电子书里 |

报告包含本机路径，发 Issue 前请脱敏。关闭应用会丢失未导出的会话报告，不会删除已生成书籍。更新时把新版本解压到新目录，先用练习验证再切换快捷方式；旧目录保留即可退回。卸载可在关闭应用后移走程序目录，先另存其中自行放入的书籍和报告。

| 问题 | 处理与恢复 |
| --- | --- |
| EXE 无反应、提示缺少 `_internal`、DLL 或 Qt 插件 | 重新完整解压到新文件夹，不单拷 EXE；查看系统隔离记录，不从网站补 DLL。仍失败则提供系统版本、ZIP 校验、原错误。 |
| 只有 `.py` 文件，没有 EXE | 下载了源码包。普通下载路线选择 Release 的 portable ZIP；源码则按 uv 路线启动。 |
| 找不到 TXT、没有可合并内容 | 确认选择的是装 TXT 的文件夹，文件扩展名确为 `.txt`，文件名以 `[作者]` 开头。 |
| 输出已存在 | 选择新的空输出目录或新文件名；不要勾选覆盖来碰运气。 |
| 失败、取消或警告 | 保留输入，核对结果列表：部分批量任务可能已完成若干输出，取消不代表全部回滚。只对失败项用新输出重试。 |
| 新版设置损坏 | 按提示路径先备份 `settings.json`，关闭应用后将其改名为 `settings.json.bak` 再启动；只重置界面设置，不动书籍。旧 Release 可能没有此设置页。 |
| `uv` 找不到或下载依赖超时 | 新开终端确认安装/PATH；核对代理和官方源。可参照 README 临时镜像说明，完成同步后再启动，不改全局安全策略。 |

验证范围与仍待完成的环境验收见 [教程验证记录](beginner-verification.md)。
