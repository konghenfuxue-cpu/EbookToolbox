# EPUB 图片压缩工具（手机阅读版）

## 推荐结论

默认选择 **1. 手机均衡**。它会把超大图片最长边限制为 2400 px，并以 JPEG 质量 72 保存。对 iPhone、安卓手机和普通平板全屏阅读通常足够清晰，体积也会明显下降。

你提供的压缩日志把 2205×3927 的单页压到约 70–175 KB，107 张共节省 104.65 MB。这属于偏激进压缩：手机不放大时大多能看，但漫画细字、网点、彩色插图渐变在放大后可能出现糊边或色块。默认“手机均衡”会比该日志略大，但画质更稳。

## 三种模式

| 模式 | JPEG 质量 | 最长边 | 适合场景 |
|---|---:|---:|---|
| 1. 手机均衡（推荐） | 72 | 2400 px | 手机日常阅读，兼顾画质与体积 |
| 2. 手机高画质 | 82 | 3000 px | 漫画细字、平板、经常放大 |
| 3. 极限省空间 | 58 | 2000 px | 只在手机全屏看，优先节省空间 |

如果想尽量接近日志中的体积，选择模式 3；如果是文字小说中的少量彩插，建议模式 1 或 2。

## 使用方法

1. 将 `EPUB图片压缩.cmd` 与 `epub_image_shrink.py` 放在同一文件夹。
2. 双击 CMD，输入 EPUB 文件或文件夹路径；也可以把单个 EPUB 或文件夹拖到 CMD 上。
3. 选择压缩模式，直接按 Enter 使用推荐模式 1。
4. 输出保存在原文件旁边，文件名增加 `_optimized.epub`；原书不会被覆盖。

首次运行如果缺少 Pillow，CMD 会尝试自动安装。需要 Python 3。

## 安全改进

- 自动跳过已经生成的 `_optimized.epub`，避免重复套娃压缩。
- 默认通过 OPF 元数据识别并跳过封面，不只依赖文件名。
- PNG 保持 PNG，不会把透明图片变成白底，也无需改 EPUB 引用。
- 新图片至少缩小 5% 且节省 8 KB 才替换，避免无意义的有损重编码。
- 修正 EXIF 旋转；重采样时使用高质量 Lanczos。
- EPUB 的 `mimetype` 始终放在首位且不压缩。
- 输出前后执行 ZIP 完整性检查；先写临时文件，成功后才生成正式结果。
- 拒绝 EPUB 内不安全的路径，原 EPUB 永远保留。

## 建议检查

批量处理前先测试一本，并在手机上抽查：

- 封面和目录能否正常显示；
- 字体较小、网点密集或颜色渐变的页面；
- 放大到你平时会用的倍率是否仍然清楚；
- Calibre 或 Sigil 能否正常打开。

确认满意后再批量运行。若模式 1 仍觉得糊，改用模式 2；若只在手机竖屏全页看且希望更小，改用模式 3。
